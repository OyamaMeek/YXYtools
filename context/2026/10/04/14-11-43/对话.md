## 助手

妹妹，这个项目已经有 [GitHub Actions 工作流](/Users/oyamahappa/Documents/GitHub/YXYtools/.github/workflows/monitor.yml)，可以直接使用。

**机密信息放在仓库的 Actions Secrets 中：**

打开 [Secrets 设置页面](https://github.com/OyamaMeek/YXYtools/settings/secrets/actions)，点击 **New repository secret**，配置这三项：

| Secret 名称 | 填写内容 |
|---|---|
| `YXY_LOGIN_CONFIG` | 本地 `work/client-private.json` 的完整 JSON 内容 |
| `TELEGRAM_BOT_TOKEN` | Telegram 机器人的 Token |
| `TELEGRAM_CHAT_ID` | 接收消息的 Chat ID |

登录 JSON 包含 `school_name`、`ym_id`、`device_id`、`token`、`session_secret`、`wallet_no`；其中 `session_secret` 填完整登录响应中的 `uuToken`。

工作流已经通过下面的写法读取机密，无需把实际值写入代码：[GitHub 官方说明](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets)。

```yaml
env:
  YXY_LOGIN_CONFIG: ${{ secrets.YXY_LOGIN_CONFIG }}
  TELEGRAM_BOT_TOKEN: ${{ secrets.TELEGRAM_BOT_TOKEN }}
  TELEGRAM_CHAT_ID: ${{ secrets.TELEGRAM_CHAT_ID }}
```

**部署和运行步骤：**

1. 将项目代码及 `.github/workflows/monitor.yml` 推送到 GitHub 默认分支，并保留用于保存监测状态的 `state` 分支。
2. 在上述设置页面确认三个 Secret 已配置。项目记录显示此前已上传，可以直接检查名称是否存在。
3. 打开 [Actions 页面](https://github.com/OyamaMeek/YXYtools/actions)，选择 **Campus card balance monitor → Run workflow**。
4. 查看运行结果。现有配置每天北京时间 **07:30 至 22:30，每半小时运行一次**；夜间手动运行也会跳过业务查询。

本地 `.env` 和私有登录 JSON 已被 `.gitignore` 排除，不要上传，也不要把凭证写入工作流或打印到日志。登录会话失效后，更新 `YXY_LOGIN_CONFIG` 即可。
